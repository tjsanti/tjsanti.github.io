# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to the label used in this repository.

| Skill role        | GitHub label       | Meaning                                   |
| ----------------- | ------------------ | ----------------------------------------- |
| `needs-triage`    | `needs-triage`     | A maintainer needs to evaluate the issue  |
| `needs-info`      | `needs-info`       | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent`  | Fully specified and ready for an agent    |
| `ready-for-human` | `ready-for-human`  | Requires human implementation             |
| `wontfix`         | `wontfix`          | Will not be implemented                   |

When a skill refers to a triage role, use the corresponding GitHub label from this table.
